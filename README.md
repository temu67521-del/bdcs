# BDCS — Bahir Dar Computer School

Student registration & payment system for Bahir Dar Computer School, Ethiopia.

## Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** PHP 8.2 + Apache
- **Database:** PostgreSQL
- **Payments:** Telebirr & CBE Birr (admin-verified)
- **Deploy:** Docker on Render

## Features
- 🎓 17 courses across Basic Computer, Programming, Maintenance, Design
- 💳 Telebirr & CBE Birr payment options
- 👨‍🏫 Teacher profiles with photo, bio, and course count
- 📊 Admin dashboard with verify/reject payment flow
- 📥 CSV export
- 🖨️ Printable receipt pages
- 📍 Google Maps location
- 🔐 bcrypt admin authentication
